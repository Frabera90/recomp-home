# RE-COMP Visual Rules

## General

- Use light surfaces as the default app environment.
- Use dark immersive surfaces only for diagnostic, recovery or focused detail moments.
- Use one primary accent color per screen.
- Keep data modules stable and readable.

## Avoid

- Gradients as decoration.
- Neon.
- Oversized shadows.
- Glowing cards.
- Busy transparent surfaces behind dense data.
- More than one visual focus per screen.

## Glass

Liquid Glass should support interaction hierarchy.

Use it for:

- Navigation
- Floating actions
- Contextual controls
- Overlays
- Temporary filters

Avoid it for:

- Biomarker tables
- Dense charts
- Long text
- Main metric cards that require stable reading
