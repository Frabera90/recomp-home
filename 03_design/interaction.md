# RE-COMP Interaction Rules

## States

Every reusable component should define:

- Default
- Hover
- Pressed
- Focus
- Disabled
- Loading
- Empty
- Error
- Success

## Interaction Tone

Interactions should feel precise and calm.

Use subtle feedback. Avoid playful movement.

## Hover

Hover may:

- Increase clarity
- Reveal contextual controls
- Add a subtle border or light sweep
- Slightly elevate an interactive surface

Hover should not:

- Create visual noise
- Change layout dramatically
- Make nearby content unreadable

## Pressed

Pressed states should feel tactile and immediate.

Recommended behavior:

- Micro scale down
- Slight brightness change
- No bounce

## Loading

Use skeletons for data content.

Use progress only when duration is meaningful.

Never show fake medical certainty while loading.
