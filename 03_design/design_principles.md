# RE-COMP Design Principles

## 1. One Decision Per Screen

Every screen should help the user make one clear decision.

Avoid dashboards full of equal-weight information.

## 1A. Composition Before Components

Do not judge a screen by the quality of its individual components.

Judge it by the clarity of the whole composition.

Every screen needs:

- one focal point
- restrained supporting elements
- intentional whitespace
- clear grid discipline
- minimal accent usage
- no decorative competition

Use `03_design/composition_principles.md` as the finish gate for every app, landing and design-system screen review.

## 2. Calm Over Stimulation

RE-COMP is not a fitness hype app.

Interfaces should reduce cognitive load. Whitespace is a feature.

## 3. Data Before Decoration

Animations and glass effects never replace information.

Visual effects should clarify hierarchy.

## 4. Progressive Disclosure

Show only what is needed first.

Complexity should emerge only when requested.

## 5. Health Is Confidence

Never create anxiety.

Scores must always include context and a next action.

## 6. Motion Explains Structure

Motion is functional.

Never animate for decoration.

## 7. Glass Belongs To Interaction

Glass is used mainly for controls, navigation and transient overlays.

Data surfaces remain stable, readable and proprietary to RE-COMP.

## 8. Trust Before Beauty

The emotional target is:

`I completely trust this product.`

Not:

`This interface looks beautiful.`

If a visual choice makes the product feel more designed but less trustworthy, remove it.
