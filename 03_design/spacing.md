# RE-COMP Spacing Scale

Use this spacing scale unless there is a clear component-level reason not to.

- 4
- 8
- 12
- 16
- 24
- 32
- 48
- 64
- 96

## Rules

- Do not invent new spacing values casually.
- Use larger spacing to reduce cognitive load on health surfaces.
- Dense clinical lists may use tighter spacing only when scanability improves.
- Touch targets should remain comfortable on mobile.
