## Main Direction

The strongest app direction is a light-first Health OS with selective dark glass modules.

The reference successfully combines:

- large health numbers
- calm white backgrounds
- biometric cards
- plan-oriented daily guidance
- AI as a decision layer
- premium medical-wellness tone

## Useful Patterns

### Health Score Home

Use a large score with:

- status
- trend
- compact sub-metrics
- AI insight
- today's focus

### Biomarker List

Use clean rows with:

- biomarker name
- value
- range indicator
- category filters
- full report CTA

### Dark Insight Surface

Use dark glass for:

- score breakdown
- AI insight
- premium biometric interpretation
- deep analysis

This should be occasional, not the default screen style.

### Plan Screen

Daily plan should combine:

- morning check
- training
- nutrition
- mobility
- breathing
- completion state

This supports the Health OS idea better than a feature menu.

### AI Coach

AI should be contextual and productized.

It should not feel like a generic blank chatbot.

## Reusable Direction For RE-COMP

RE-COMP app UI should use:

- white foundation
- precise health data
- dark glass insight modules
- subtle blur accents
- large numbers
- concise explanations
- action-oriented recommendations

## Risks

- The concept may become too close to Bevel/Superpower if copied too directly.
- Decorative orb elements should be avoided or heavily reduced.
- Chat UI should not become the main product metaphor.
