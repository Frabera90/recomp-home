# RE-COMP Composition Principles

## Core Shift

RE-COMP screens must not feel like collections of refined components.

They must feel composed.

Every screen should have the discipline of an Apple Health surface, a WHOOP flow, an Everlab report or an Apple keynote slide:

- one focal point
- calm hierarchy
- intentional whitespace
- restrained materials
- minimal accent usage
- few competing visual events

The objective is not to make the interface look beautiful.

The objective is to make the interface feel inevitable.

## 1. Subtract Before Adding

Before adding a visual element, remove everything that is not necessary.

If removing an element does not reduce clarity, usability or trust, remove it.

This applies to:

- borders
- dividers
- glows
- badges
- icons
- labels
- secondary metrics
- decorative gradients
- redundant cards
- repeated accent colors

## 2. Less Components, More Composition

Do not optimize isolated components first.

Optimize the relationship between elements:

- alignment
- rhythm
- relative scale
- whitespace
- focus
- reading order
- density
- proximity

A screen can contain excellent components and still fail if everything has equal visual importance.

## 3. One Focal Point

Every screen must have one dominant visual element.

Everything else supports it.

If two or more elements compete for primary attention, reduce one of them.

The focal point can be:

- a primary metric
- a user decision
- a next action
- a status summary
- a transformation moment
- a professional recommendation

## 4. Whitespace Is Functional

Empty space is not unused space.

It creates:

- trust
- hierarchy
- comprehension speed
- editorial rhythm
- premium calm

Do not fill available space only because the layout allows it.

## 5. Materials Should Disappear

Soft Metal and Liquid Glass are not the subject of the product.

Users should notice information, guidance and confidence before noticing material effects.

Reduce:

- visible borders
- contrast-heavy cards
- glow
- heavy elevation
- decorative refraction
- glass used as spectacle

Cards should feel integrated into the surface and become more apparent only through interaction or hierarchy.

## 6. Accent Colors Are Rare

Accent colors are allowed mainly for:

- selection
- confirmation
- active state
- primary action
- module identity only when needed for orientation

Green, blue, purple and gold must not be scattered across the screen as decoration.

Default interface color is neutral.

Premium comes from restraint.

## 7. Typography Must Be Editorial

Typography should state, not explain.

Use shorter headlines.

Increase breathing room.

Avoid oversized dense titles unless the screen genuinely needs a hero-scale statement.

Prefer:

- `Guidance over metrics`
- `Signals become guidance`
- `Recovery is ready`
- `Review your baseline`

Avoid explanatory headlines that turn the screen into documentation.

## 8. Cards Are Sections, Not Objects

Cards must not look like floating UI blocks competing for attention.

Reduce:

- border visibility
- card contrast
- glow
- elevation
- internal decoration

Cards should read as sections of a composed surface.

Only interactive or selected surfaces may gain stronger visibility.

## 9. Grid Discipline

Every screen must feel engineered.

Margins repeat.

Columns align.

Spacing follows a rhythm.

Elements do not drift.

If alignment is unclear, the screen is not finished.

## 10. Motion Explains Relationships

Motion is allowed only when it explains:

- hierarchy
- relationship
- transition
- focus
- continuity

Motion must be subtle and almost invisible.

Never theatrical.

## Finish Gate

Before considering a screen finished, ask:

`What can I remove?`

Repeat until removing another element would genuinely reduce clarity, usability or trust.

Then check:

- Is there exactly one focal point?
- Are accents rare and meaningful?
- Are cards integrated into the surface?
- Does whitespace carry hierarchy?
- Can the user understand the screen in under two seconds?
- Does the screen feel calm, confident and trustworthy?

If the answer is no, the screen is not finished.
