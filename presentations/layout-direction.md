# RE-COMP Presentation Layout Direction

## Status

Draft scaffold. Final layout should follow the approved visual language and the eventual deck objective.

## Layout Principles

- Dark premium base.
- Calm editorial rhythm.
- Large visual proof when available.
- Sparse copy.
- Clear hierarchy.
- No generic SaaS cards-as-decoration.
- Use screenshots, mockups, generated images and logo assets as evidence.

## Visual System

- Background: dark Soft Metal or cinematic dark surfaces.
- Glass: limited to captions, overlays, callouts and navigation-like slide elements.
- Light: used to reveal hierarchy, not decorate.
- Typography: restrained, precise, high legibility.
- Color: use RE-COMP module colors as accents only.

## Slide Types

- Opening statement.
- Problem framing.
- Product architecture.
- User journey.
- Module explanation.
- Visual language proof.
- App proof.
- Landing proof.
- Social/brand proof.
- Roadmap and next steps.
