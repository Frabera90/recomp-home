# Flow Engine

After every task, evaluate the system state.

## Evaluation Questions

- is onboarding complete?
- is retention defined?
- is AI integrated properly?
- are flows complete?
- are user states clear?
- are recommendations actionable?
- does the UI match the product positioning?

## Suggested Next Step Types

Use one of:

- missing flow
- next UX priority
- system gap resolution
- component refinement
- content definition
- visual reconciliation
- product risk review

## Rule

The system should evolve through structured updates, not isolated screens.
