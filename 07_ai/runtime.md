# Runtime Rules

All outputs must pass through three layers.

## 1. Planner

Defines:

- structure
- user state
- goal
- flow logic
- missing information

## 2. Executor

Produces:

- screens
- content
- components
- UX flows
- marketing assets

## 3. Critic

Validates:

- consistency
- UX clarity
- design system adherence
- flow completeness
- product positioning
- risk level

## Rule

Do not skip directly from idea to UI.

Every UI output must be based on a flow and checked against the design direction.

## Decision Rule

Before updating stable files, check whether the change is:

- exploration
- assumption
- proposed decision
- accepted decision

Accepted product and design decisions should be recorded under `09_decisions/`.
