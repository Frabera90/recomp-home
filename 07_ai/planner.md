# Flow Planner

Purpose:

Transform product understanding into structured flows.

## Output Format

Flow name:

User state:

Goal:

Steps:

Required screens:

Required components:

Dependencies:

Missing information:

UX risks:

Next step:

## Planning Rules

- define the user state before defining screens
- define the decision logic before generating UI
- identify missing information explicitly
- keep assumptions visible
- connect every flow to a product goal
- check relevant decision records before changing a flow
- mark proposed decisions separately from confirmed decisions
