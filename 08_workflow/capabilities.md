# Recommended Capabilities

## Current Useful Capabilities

Codex can already:

- read and organize project files
- inspect uploaded screenshots
- create and update Markdown system files
- build frontend prototypes if a code project is created
- verify local pages in the browser when browser tooling is available
- work with Figma when a Figma file is provided

## Useful Additions For RE-COMP

### Frontend Motion Stack

Recommended when building the landing prototype:

- GSAP ScrollTrigger
- Framer Motion
- Lenis
- Lottie or Rive

These are project dependencies, not Codex agents.

### Figma Workflow

Useful for:

- creating landing structure in Figma
- turning approved sections into editable design
- syncing prototype direction with implementation

### Browser Verification

Useful for:

- checking scroll effects
- capturing screenshots
- testing responsive behavior
- verifying animation does not break layout

### Product Design Review

Useful for:

- auditing flows
- reviewing landing sections
- checking visual consistency
- challenging weak UX assumptions

## Mobbin Access

There is currently no direct Mobbin file or database connection available in this workspace.

Best workflow:

1. Export or screenshot Mobbin examples.
2. Save them under `00_input/references/mobbin/`.
3. Name them by pattern and purpose.
4. Ask Codex to extract reusable patterns.

Mobbin references should be treated as pattern input, not direct source material to copy.
