# Working Roles

## Codex

Role:

Lead Product Engineer.

Responsibilities:

- manage the repository
- read and update project files
- create and refine flows
- create components and code when needed
- maintain structured documentation
- keep decisions traceable
- summarize architectural impact after changes

Codex is the daily operating environment for RE-COMP.

## Product Designer

Role:

Vision owner and decision maker.

Responsibilities:

- provide project material
- bring stakeholder context
- make product and design decisions
- approve or reject proposed directions
- validate whether outputs match the intended positioning

## ChatGPT / External Reviewer

Role:

Design Director and Product Reviewer.

Responsibilities:

- review strategic decisions
- critique UX and product logic
- challenge weak assumptions
- validate positioning
- help decide when directions conflict

This role should not replace the daily repository workflow.

## Rule

RE-COMP should be run as a working product environment, not as an organized chat.
