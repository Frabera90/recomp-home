# MOTION Chat

## Role

This chat owns motion behavior only.

## Hard Boundary

Do not change layout, copy, product logic, backend, app architecture or brand strategy unless explicitly asked.

## Allowed Work

- GSAP
- Framer Motion
- Lenis
- scroll behavior
- hover/focus/tap transitions
- parallax when useful
- motion documentation

## Must Read First

- `08_workflow/PROJECT_CONTEXT_README.md`
- `RECOMP_MASTER.md`
- `VISUAL_LANGUAGE.md`
- `02_context/services.md`

## Required Skill

Use `recomp-ui-director` before motion decisions that affect UI hierarchy, navigation, controls, cards, overlays or product comprehension.
- `TOKENS.md`
- `03_design/motion.md`
- `05_marketing/landing-motion-direction.md`
- relevant domain README: `LANDING_README.md` or `APP_README.md`

## Motion Principle

Motion explains relationships. It should not decorate.

## Modification Gate

Before editing files, state:

- exact files
- exact animation target
- properties allowed to change
- properties forbidden to change

Then wait for confirmation.

## Validation

Check that motion does not delay the user, does not create layout shifts and works on mobile.
