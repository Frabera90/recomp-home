# App UI Pilot Implementation Gate

Do not implement UI until the structure is approved.

## Before Coding

For any pilot screen, define:

- User purpose
- Primary decision
- Component tree
- New components
- Assumptions
- Native Liquid Glass usage
- Proprietary RE-COMP surfaces
- Responsive behavior
- Motion behavior

## After Coding

For any pilot screen, perform:

- Desktop visual review
- Mobile visual review
- Interaction review
- Documentation update
- List of items to validate against real code

## First Implementation Candidate

Home / Daily Overview.

Reason:

It tests the most important product question: "How am I today and what should I do?"
