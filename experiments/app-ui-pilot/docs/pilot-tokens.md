# App UI Pilot Tokens

## Status

Provisional.

These tokens describe direction, not final implementation.

## Color Roles

### Base

- App background: soft off-white
- Primary surface: white
- Secondary surface: cool gray
- Text primary: graphite
- Text secondary: muted gray

### Diagnostic

- Diagnostic background: graphite / near black
- Diagnostic surface: dark glass
- Diagnostic text: white
- Diagnostic secondary text: soft gray

### Functional Accents

- Recovery: ice blue
- Nutrition: muted green
- Biomarkers: teal / violet
- Coaching: warm neutral
- Success: health green
- Attention: warm amber

## Radius

- Controls: pill or high radius
- Data cards: moderate radius
- Diagnostic panels: larger radius
- Dense rows: controlled radius

Avoid making every component a capsule.

## Elevation

Use minimal shadows on light surfaces.

Use depth mainly to separate interaction layers from content layers.

## Glass

Glass is a behavior layer, not a default content material.

Use for:

- Tab bar
- Composer
- Quick action controls
- Overlays

Avoid for:

- Main data cards
- Biomarker rows
- Charts
- Reports
