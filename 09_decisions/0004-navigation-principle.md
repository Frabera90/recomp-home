# Decision 0004: Navigation Principle

## Status

Proposed

## Decision

Navigation should prioritize user state and action before feature categories.

## Reason

RE-COMP includes many domains: health, recovery, nutrition, performance, coaching and biomarkers.

If navigation simply mirrors all features, the product may feel complex and fragmented.

## Consequences

- A `Today` or equivalent home state should likely be central.
- Health state and recommendations should be easy to access.
- Deep sections can exist, but the user should always know what matters now.
- Navigation labels should be finalized after onboarding and dashboard flows are clearer.
