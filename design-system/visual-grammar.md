# RE-COMP Visual Grammar

## Purpose

This is the primary creative brief for the RE-COMP Design System.

Do not start from components.

Start from the visual grammar:

- material
- light
- depth
- refraction
- motion
- space
- rhythm
- perception

The goal is to make RE-COMP feel like a health operating system with an Apple-level material logic and a RE-COMP-specific identity.

## Core Shift

Do not ask:

`Create a design system.`

Ask:

`Design the visual grammar of RE-COMP.`

These are different tasks.

A design system often becomes:

- palette
- typography
- buttons
- cards
- inputs
- spacing
- icons

That is not enough.

RE-COMP needs the underlying laws that govern the interface.

## Two Volumes

### Volume 1: Visual Language

This is the priority.

It explains the physics and perception of the interface.

It should feel like an internal industrial design document:

- Apple Human Interface
- Nothing
- Teenage Engineering
- Linear
- Stripe
- IDEO
- Frog

Almost no components.

Focus:

- materials
- light
- depth
- motion
- refraction
- visual physics
- hierarchy
- rhythm
- space
- philosophy

### Volume 2: Component Library

This comes later.

It translates the visual language into:

- buttons
- cards
- inputs
- navigation
- charts
- KPI modules
- search
- sheets
- modals
- tooltips
- toasts

Do not let Volume 2 dominate before Volume 1 is strong.

## Board Direction

The Design System board should feel like a laboratory, not a component catalog.

It should not be 20 components aligned in rows.

It should explain how RE-COMP's interface behaves.

## Board 01: Material Physics

Show:

- how glass behaves
- how it refracts
- how it changes on black
- how it changes on photography
- how it changes with motion
- exploded layers
- reflections
- blur
- edge highlights
- tint

Do not show:

- generic button rows
- decorative glass cards without explanation

## Board 02: Depth System

Show an exploded depth stack:

1. System Overlay
2. Modal
3. Floating Controls
4. Glass
5. Content
6. Background

Include:

- shadows
- arrows
- distance markers
- opacity changes
- hierarchy notes

## Board 03: Light Behaviour

Show only light.

Explain:

- where light enters
- how it hits glass
- how it illuminates edges
- how it creates depth
- when it disappears
- when it becomes stronger

## Board 04: Refraction

Show the same control over:

- photography
- black
- graphite
- soft gray
- gradient
- glass

Explain how the material adapts.

## Board 05: Interaction

Do not show static buttons.

Show the timeline:

1. Default
2. Hover
3. Focus
4. Pressed
5. Released
6. Rest

Use frames, annotations and transition rules.

## Board 06: Motion

Show:

- curves
- velocity
- spring
- elasticity
- overshoot limits
- shared element motion
- morph behavior
- reduced motion fallback

Motion must explain a relationship.

## Board 07: Glass Construction

Show an exploded component:

1. Reflection
2. Glass Layer
3. Tint
4. Blur
5. Noise
6. Shadow
7. Ambient Light
8. Content

It should feel like a patent drawing or Apple material study.

## Board 08: Spatial System

Do not start with a generic grid.

Show how elements breathe:

- proximity
- safe areas
- floating control clearance
- content density
- silence/empty space
- relation between primary decision and supporting signals

## Board 09: Material Tokens

Do not start with colors.

Start with materials:

- Glass Regular
- Glass Thin
- Glass Strong
- Glass Adaptive
- Diagnostic Graphite
- Health Paper
- Solid Content
- Transparent Overlay

Each token must explain:

- role
- background dependency
- blur
- tint
- edge behavior
- accessibility fallback

## Board 10: Adaptive System

Show how the material changes across:

- mobile
- tablet
- desktop
- watch
- TV
- spatial/vision

The material may change, but the RE-COMP identity must remain continuous.

## RE-COMP Fusion

The provided visual reference is useful for:

- dark premium board mood
- modular layout
- restrained glow
- RE-COMP module colors
- glass controls
- typography atmosphere

But it is still too much like a UI kit.

Use it as a mood reference, not as the structure.

The target is:

- more Liquid Glass physics
- more material behaviour
- more light/refraction studies
- less component catalog
- less decorative dashboard

## What Good Looks Like

A good RE-COMP visual grammar board should make someone understand:

- how the glass behaves
- why depth exists
- when light appears
- why a control floats
- how RE-COMP differs from generic fitness apps
- how health information stays readable

Before they ever see a button component.

## Output Rule

When asked to work on the Design System, start by deciding:

- Is this Volume 1 Visual Language?
- Or Volume 2 Component Library?

Default to Volume 1 unless the user explicitly asks for components.
