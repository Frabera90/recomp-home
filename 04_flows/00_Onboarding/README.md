# 00 Onboarding

## Purpose

Bring the user from first contact to a usable baseline without inventing new backend logic unless approved.

## Primary User Decision

The user must understand what RE-COMP will guide, what data is needed, and what comes next.

## Current Priority

P0.

This is the first app flow to review because it connects registration, role setup, baseline and the path toward Home and Food Tracker.
