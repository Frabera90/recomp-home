# RE-COMP Approved Decisions Index

This file is a short index. Full decision records live in `09_decisions/`.

## Accepted

### 0001 Health OS Positioning

RE-COMP is moving toward a Health OS / Human Optimization Platform rather than a generic fitness tracker.

### 0002 Light-First Interface

The default experience should be light, clean and controlled, with dark/glass modules used selectively.

### 0003 Glass Rules

Glass is a controlled material for hierarchy and transient surfaces, not a blanket style.

### 0004 Navigation Principle

Navigation should serve clarity and daily usefulness before visual novelty.

### 0005 Information Density

Product screens must be useful enough for repeated use while staying calm and readable.

### 0006 Landing And App UI Separation

Landing and app UI are separate surfaces. Landing may be narrative and visually expressive. App UI must be operational, structured and calm.

### 0007 Liquid Glass Adoption

Liquid Glass is accepted for native usability surfaces such as navigation, controls, contextual actions and overlays. It is not the default material for dashboards, reports, lists, tables or dense metric cards.

### 0008 UI Pilot Scope

The app UI pilot is provisional and must be reconciled with the old app and Claude redesign audit before becoming final product architecture.

## Decision Rule

When a new decision is made, add a full record to `09_decisions/` and update this index.
