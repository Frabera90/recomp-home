# RE-COMP Logo Asset System

## Source Assets

`brand/logo/source/` contains visual references and concept boards.

These are not final production assets.

## Master Assets

`brand/logo/master/` will contain clean SVG masters.

Rules:

- no embedded PNG
- no image tracing output
- no filters
- no glow
- no mandatory background container
- minimal paths
- clean viewBox
- rounded terminals
- consistent optical stroke weight

## Variants

`brand/logo/variants/` will contain white, black, inverse and dark-neutral variants.

Do not create one logo per product module color. Recovery, Nutrition, Biomarkers and Coaching are interface states, not logo variants.

## Optimized Assets

`brand/logo/optimized/` will contain favicon and small-size optical variants.

Small-size variants may use slightly heavier stroke or simplified geometry, but must not distort the main master.

## PNG Exports

`brand/logo/png-exports/` will contain rendered exports at:

- 16 px
- 32 px
- 64 px
- 128 px
- 256 px
- 512 px
- 1024 px
