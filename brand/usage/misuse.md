# Logo Misuse

Do not:

- use an auto-traced PNG as the official logo
- embed the glass background inside every logo file
- add glow, blur or shadow to the core logo
- recolor the logo per module
- compress or stretch the symbol
- use the wordmark as a raster screenshot
- place the logo on low-contrast media without a legibility container

Allowed:

- use a separate glass UI container around the logo in navigation or app chrome
- use white or black variants depending on background
- use the symbol alone for favicon, app icon and compact chrome
