# Minimum Size

Temporary targets to validate during SVG reconstruction:

- Favicon: 16 px, optimized variant required.
- Compact nav symbol: 24 px minimum.
- Preferred nav symbol: 28-32 px.
- Horizontal navbar logo: 120-180 px wide depending on context.
- App icon: 1024 px source, exported down through system sizes.

If the master loses clarity at 16-24 px, create a small-size optical variant instead of compromising the master.
