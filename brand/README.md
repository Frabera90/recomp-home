# RE-COMP Brand

## Purpose

This folder is the home of the RE-COMP brand book.

It documents the identity system behind the product: logo, color, typography, imagery, motion, voice, usage rules and brand applications.

## Source Of Truth

Before changing brand documentation, read:

- `VISUAL_LANGUAGE.md`
- `RECOMP_MASTER.md`
- `DECISIONS.md`
- `TOKENS.md`
- `02_context/product.md`
- `02_context/positioning.md`
- `02_context/product_philosophy.md`
- `03_design/voice.md`
- `brand/brand-guidelines.md`

## Sections

- `brand-guidelines.md`: current high-level brand guidance.
- `foundation/`: positioning, promise, personality and core brand logic.
- `logo/`: logo files, logo notes and approved logo references.
- `usage/`: clear space, minimum size and misuse rules.
- `color/`: color palette and color behavior.
- `typography/`: typography direction and font usage.
- `imagery/`: photography, generated image and visual art direction.
- `motion/`: motion identity and logo motion.
- `applications/`: app, landing, social, presentation and generated image usage.
- `governance/`: asset status, freeze rules and decision workflow.

## Connected Systems

Branding informs:

- app UI
- landing
- design system
- social
- presentation
- generated images and mockups

Those systems may read the brand book. They should not redefine brand identity independently.
