# RE-COMP Typography System

Status: draft foundation

## Principle

Typography creates hierarchy before color does.

RE-COMP type should feel calm, precise and premium. It should never feel loud, gamified or promotional.

## Current Implementation Direction

The current token snapshot uses:

- Sans: Inter, system UI, Apple system fallback
- Mono: SF Mono / Roboto Mono / monospace fallback

These are acceptable working fonts, not a final brand type decision.

## App Typography

The app should prioritize:

- readability
- clear state
- confident numbers
- short interpretations
- one primary decision per screen

App text should feel native-aware and efficient.

Avoid:

- oversized marketing headlines inside operational screens
- tiny dense captions for important health explanations
- decorative type treatments
- negative letter spacing
- hype phrases

## Marketing And Social Typography

Marketing and social may use a more editorial display voice than the app.

Allowed:

- larger headlines
- strong scale contrast
- refined editorial composition
- short, memorable lines

Required:

- high legibility
- restrained layout
- no unsupported medical certainty
- no motivational fitness language

## Data Typography

Data numbers should be:

- large enough to scan
- calm
- confident
- paired with interpretation

Never show raw numbers without context when the surface is intended to guide action.

## Open Decisions

- Final brand type pairing is not selected.
- Editorial display type for social and campaigns is not selected.
- App type scale needs reconciliation with the final app codebase.
