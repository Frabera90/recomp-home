# System Map

RE-COMP is composed of three main systems.

## 1. Customer System

The customer system helps individuals understand and improve their health state.

Includes:

- onboarding
- health assessment
- AI blueprint
- daily guidance
- nutrition tracking
- recovery tracking
- performance tracking
- health insights
- biomarker review
- appointment booking

## 2. Coach System

The coach system helps professionals monitor, guide and support customers.

Includes:

- coach dashboard
- client overview
- progress monitoring
- health state summaries
- action recommendations
- notes and communication layer

## 3. Franchise System

The franchise system helps RE-COMP scale operations.

Includes:

- operator onboarding
- management tools
- analytics
- client distribution
- coach performance overview
- operational control

## System Logic

Data should move from customer behavior and health inputs into interpretation, then into recommendations and actions.

The user should not be left alone with numbers.
