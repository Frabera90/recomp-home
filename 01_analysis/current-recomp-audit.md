## Current State

The current RE-COMP screens communicate a functional fitness and nutrition tool.

They do not yet communicate a premium Health OS.

## What To Preserve

- Light background foundation
- Card-based structure
- Daily target logic
- Nutrition and macro planning
- Coach/user relationship concept
- Morning check behavior
- Daily/weekly data orientation
- Bottom navigation as a familiar mobile pattern

## What To Redesign

- Oversized rounded cards and circular icon buttons
- Generic gradient CTA styling
- Large unstructured icon grid
- Weak hierarchy between health, training and nutrition
- Prototype-like labels and copy
- Visual language that feels closer to a fitness utility than health intelligence

## Main UX Issues

- Too many actions appear at the same priority level.
- Data is shown without enough interpretation.
- The interface relies on raw controls rather than guided recommendations.
- The coach identity is present but not systematized.
- Nutrition screens feel operational, but not premium or intelligent.

## Branding Issues

- The current style does not yet express Apple / Bevel / Superpower / Nike quality.
- The red-to-purple gradient feels generic and heavy.
- The icon style is too large and basic for the desired premium positioning.
- The UI lacks a clear signature system beyond rounded white cards.

## Direction

The current UI should be treated as functional source material.

It should inform:

- available features
- existing flows
- information needs
- user tasks

It should not define the future visual system.
