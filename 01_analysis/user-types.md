# User Types

## Customer

Goal:

Improve health, energy, longevity and performance.

Needs:

- guidance
- clarity
- simplicity
- motivation
- trust
- progress visibility

Risks:

- feeling overwhelmed
- not understanding medical or biometric data
- losing consistency

## Coach

Goal:

Monitor and guide users effectively.

Needs:

- client overview
- data interpretation
- progress monitoring
- alerts
- communication tools

Risks:

- too much data without prioritization
- unclear client status
- slow workflow

## Franchise Operator

Goal:

Manage the system at scale.

Needs:

- analytics
- onboarding flows
- operations control
- coach and client visibility
- scalable reporting

Risks:

- inconsistent experience across locations
- unclear operational ownership
- fragmented data
